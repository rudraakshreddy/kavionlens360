# Power BI report (PBIP)

`KavionLens360.pbip` is a Power BI Project: the semantic model is in TMDL (`KavionLens360.SemanticModel/definition`)
and the report is in PBIR JSON (`KavionLens360.Report/definition`). Both are generated by `build_pbip.py` and checked
with Microsoft's `powerbi-report-author validate` (0 errors) and the TMDL parser (`TmdlSerializer`).

## Open and refresh

1. Run the pipeline first (`python run_pipeline.py`) so `data/exports/powerbi/*.csv` exists.
2. Open `KavionLens360.pbip` in Power BI Desktop.
3. If the repository is not at `C:\Users\chakr\Documents\rudr`, set the folder under
   **Transform data → Edit parameters → DataFolder** (keep the trailing backslash).
4. Click **Refresh**. The model imports 11 tables (about 840K customers); the first refresh takes a minute or two.

## Model

| Table | Role |
|---|---|
| `customer_360` | one row per customer; holds the measures |
| `customer_segment`, `customer_opportunity` | 1:1 with `customer_360`, filters in both directions |
| `dim_location`, `dim_date` | dimensions; `agg_daily_city` is the pre-aggregated daily fact for trends |
| `segment_definition`, `dq_log`, `row_waterfall`, `kpi_reconciliation`, `agg_hour_weekday` | lookup, audit and reconciliation |

36 DAX measures include Total Customers, Avg Txn Value, Active Rate, High Value Share, Segment Size % / Value %,
Opportunity Count, Cross-Sell Opp Rate, Addressable Balance, Tier A Customers, six theme signal counts and two
reconciliation-variance measures.

## Pages

1. **Executive Customer 360**: KPI cards, age × gender, daily trend, top cities, segment split; synced slicers.
2. **Customer Segmentation**: size vs value share, profile matrix, age mix, balance vs value scatter, segment actions.
3. **Cross-Sell Opportunities**: signal banner, KPIs, theme × segment, tier funnel, score distribution, opportunity by city.
4. **Manager Action**: ranked priority list (masked IDs) with reason, theme, city, segment and evidence; drill-through target
   for city (right-click a city bar on page 1 → Drill through).
5. **Data Quality & Reconciliation**: Power BI vs SQL variance cards, row waterfall, DQ scorecard.

## Export to PDF

File → Export → Export to PDF, then save as `docs/downloads/KavionLens360_PowerBI.pdf`. The web report links it automatically
on the next site build (`python -m c360.site`).
